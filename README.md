# النظام المحاسبي سكاي موبايل — Flutter

## الخدمات الموجودة
- لوحة تحكم وإحصائيات
- العملاء
- الديون والتسديدات/القبض
- تحويل الأرقام إلى كلمات عربية
- الأصناف والمخزون
- المبيعات والفواتير
- المشتريات والفواتير
- المصروفات
- الصندوق بشكل أولي عبر القيود
- تقارير أساسية
- إعدادات ونسخة بيانات JSON للعرض
- حفظ محلي للبيانات

## التشغيل
flutter pub get
flutter run

## APK
flutter build apk --release

ملاحظة: هذه نسخة أساس عملية، وتحتاج قبل الاستخدام التجاري الفعلي إلى اختبار شامل، وصلاحيات مستخدمين، وتشفير/نسخ احتياطي خارجي، وطباعة ومشاركة PDF، ومعالجة محاسبية أدق للضريبة والمخزون والمرتجعات.
